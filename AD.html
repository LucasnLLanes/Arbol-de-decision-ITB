1. Introducción

El presente informe documenta la aplicación de un Árbol de Decisión para predecir el abandono de estudiantes en carreras terciarias. El objetivo es identificar tempranamente a los estudiantes con mayor riesgo de desertar, para que la institución pueda implementar estrategias de acompañamiento focalizadas.

El trabajo se compone de dos partes: el script Python (AD.py) que implementa todo el pipeline, y este informe HTML que documenta el código, los resultados y las visualizaciones generadas.

2. Descripción del Dataset

El dataset contiene información histórica de 100 estudiantes con las siguientes variables:

  • Edad: edad del estudiante en años.
  • Género: femenino / masculino.
  • Carrera: carrera terciaria en la que está inscripto.
  • Promedio: promedio del primer cuatrimestre.
  • Aprobadas: cantidad de materias aprobadas.
  • Desaprobadas: cantidad de materias desaprobadas.
  • Asistencia: asistencia promedio (%).
  • Trabaja: si el estudiante trabaja (Sí/No).
  • Distancia_km: distancia desde el domicilio al instituto.
  • Actividades_Extra: participación en actividades extracurriculares.
  • Estado_Final (objetivo): Abandonó / Continúa.

3. Estructura del Script AD.py

El script se organiza en 6 bloques principales, más funciones auxiliares:

  1. Carga y preparación: lectura de Excel, renombrado, limpieza y One-Hot Encoding.
  2. División y entrenamiento: train_test_split estratificado 70/30 + DecisionTreeClassifier.
  3. Evaluación: accuracy, matriz de confusión y reporte de clasificación.
  4. Interpretación: importancia de variables y reglas del árbol.
  5. Estabilidad: prueba con 5 divisiones distintas para verificar si las importancias se sostienen.
  6. Predicción final: aplicación del modelo sobre los 100 estudiantes nuevos y exportación a Excel.

def localizar_planilla(palabra_clave):
    """Busca el primer .xlsx que contenga la palabra clave."""
    coincidencias = [f for f in glob.glob("*.xlsx")
                     if palabra_clave.lower() in f.lower()
                     and not f.startswith("predicciones")
                     and not f.startswith("~$")]
    if not coincidencias:
        raise FileNotFoundError(f"No se encontró ningún .xlsx con '{palabra_clave}'")
    print(f"Planilla cargada: {coincidencias[0]}")
    return coincidencias[0]
def limpiar_y_codificar(df):
    """Normaliza y codifica el DataFrame."""
    df = df.rename(columns=RENOMBRE).copy()
    for columna in ["genero", "carrera", "trabaja", "extracurriculares"]:
        df[columna] = df[columna].astype(str).str.strip()
    df["carrera"] = (df["carrera"]
                     .str.replace("TÉCNICATURA", "TECNICATURA")
                     .str.replace("TECNICATURA SUPERIOR EN ", ""))
    df["genero"] = df["genero"].map({"m": 0, "f": 1})
    df["trabaja"] = df["trabaja"].map({"No": 0, "Si": 1})
    df["extracurriculares"] = df["extracurriculares"].map({"No": 0, "Si": 1})
    if "estado_final" in df.columns:
        df["estado_final"] = df["estado_final"].map({"Abandonó": 1, "Continúa": 0})
    return df

9. Limitaciones y Trabajo Futuro

  • Dataset sin señal predictiva: las medias entre clases son casi idénticas y el modelo no supera al azar.
  • Tamaño reducido: 100 registros es un tamaño acotado; se recomienda ampliar con datos de varias cohortes.
  • Sobreajuste: el árbol memoriza el entrenamiento (0.80) pero no generaliza (0.50 en prueba). Se podría mitigar con poda (ccp_alpha).
  • Comparación de algoritmos: se probaron Random Forest y Regresión Logística con resultados similares o peores.
  • Consideraciones éticas: cualquier sistema de alerta temprana debe usarse para acompañar, no para estigmatizar. Las predicciones no deben usarse como etiquetas definitivas.

10. Conclusiones

El árbol de decisión demostró ser una herramienta interpretable, pero en este caso no permitió predecir el abandono con una precisión mejor que el azar. El accuracy en prueba (0.50) es menor que el de un modelo trivial que siempre predice "Abandonó" (0.53), y las variables "importantes" cambian por completo al modificar la división train/test.

El valor principal del trabajo está en haber aplicado una metodología rigurosa que incluye: análisis de medias entre clases, comparación contra un modelo trivial, validación cruzada, prueba de estabilidad con múltiples divisiones, y una comunicación honesta de las limitaciones.

Aprendizaje clave: un modelo con buen accuracy en entrenamiento puede ser inútil si no se lo compara con un baseline trivial y si no se verifica la estabilidad de sus resultados. La validación rigurosa es imprescindible antes de sacar conclusiones.
